# Outputs

Everything here is produced by `run_full_analysis.R`. Each strand writes into its
own folder, and within a strand each step writes its own subfolder, so the script
that made a given file is always obvious and re-running one step cannot overwrite
another step's work.

`Outputs/` is git-ignored — it is fully regenerated by a run, and tracking it
would invite the results on disk to drift from the code that made them. Only this
README and the provenance records under `_provenance/` are kept in version
control. To track specific supplementary tables, un-ignore those files in
`.gitignore`.

```
Outputs/
  01_bulk_rnaseq_DE/
    01_qc/{tables,figures}                      01_load_data_and_infer_sex.R
    02_differential_expression/{tables,figures} 02_differential_expression_deseq2.R
    03_enrichment/{tables,figures}              03_go_enrichment_ORA_GSEA.R
    04_wgcna/{tables,figures}                   04_coexpression_wgcna.R
    rdata/                                      per-step caches, shared between steps
  02_cross_species_comparison/
    data_raw/                                   assembled by run_full_analysis.R
    data_processed/                             standardized intermediates
    reference/                                  frozen Ensembl ortholog table
    results/{tables,figures,logs}               R/01–15
  03_scRNAseq_reference_projection/{tables,figures}   Projection.R
  _provenance/                                  sessionInfo, timings, output manifests
```

The strand-01 folder names come from `OUTPUT_STEP_DIRS` in `00_config.R`. Its
scripts resolve their own paths with `step_dir("02", "tables")` — they do not
inherit `DIR_TABLES`/`DIR_FIGURES` from the config, so a script that forgets to
set them fails loudly instead of writing somewhere unexpected. The strand-01
`rdata/` cache is deliberately shared: step 02 reads step 01's cache, and steps
03 and 04 both read step 02's.

The differential-expression table is written to
`01_bulk_rnaseq_DE/02_differential_expression/tables/S1_Table_DESeq.csv`; strand
02 reads it from there automatically.

## Figures that are absent by design

`make_go_barplot()` returns `NULL` when no term passes `p.adjust < 0.05`, and the
calling code skips `ggsave()` rather than writing a misleading empty plot. So a
handful of GO ORA tables have no matching figure, and that is correct, not a
failure — for example when up- and downregulated genes are pooled and nothing is
jointly significant. The `GSEA_theme_*.csv` files are filtered views of the GSEA
results for the manuscript's narrative themes and have no figure by design.

## Verifying a run

Every run writes to `_provenance/`:

- `sessionInfo_<timestamp>.txt` — full package versions
- `run_summary_<timestamp>.txt` — R version, platform, strands, timings
- `output_manifest_<timestamp>.csv` — every file produced, with size

See `REPRODUCIBILITY.md` at the repo root for how to compare two runs.
